# Madro

Madro er en madplansapp til familier: planen for ugen, indkøbslisten, køkkenet og madbudgettet samlet ét sted.

Repositoriet rummer konceptarbejdet indtil videre:

- `prototype/index.html` – klikbar hi-fi-prototype (åbn i en browser; skærme kan deep-linkes med `#id`, fx `#ugen`)
- `pitch/index.html` – pitch med roadmap og bevægelsessprog
- `brand/logo/` – logofiler (rødbeden "Bladet ud til siden") i lys, mørk, sort og hvid, SVG og PNG

## Brand

- Palet B "Rugbrød og rødbede": kerne `#F3EEE4`, rugbrød `#2B1D17`, rødbede `#8E1B42`, dild `#4F6E32`
- Bricolage Grotesque 700 til overskrifter, systemfont til resten
- Højst ét rødbede-element pr. skærm; grøntsagsfarver kun i illustrationer og tallerkener
